# Security

etaHEN is unofficial PS5 homebrew. There is no warranty.

If etaHEN crashes, hangs, or a setting is wrong, open a
[Bug report](https://github.com/TOSanthony/etaHEN-2.6B/issues/new?template=bug_report.yml).
Include firmware, version, how it was loaded, and logs from
`/data/etaHEN/`.

To keep a report private, use this repository's Security tab.
